# BravaDesk 0.7.1

Atualize somente src/App.jsx, src/main.jsx e src/index.css no GitHub. Nenhuma alteração SQL ou VAPID é necessária.

Após o login, dispositivos compatíveis sem push registrado recebem um convite para ativar. O botão pede permissão nativa; Agora não adia por 24 horas. Inscrições antigas com permissão concedida são revalidadas na conta. A preferência de tema é local; o primeiro acesso segue o sistema operacional. O seletor lua/sol aparece no login e cabeçalho.

O ZIP completo contém os arquivos da v0.7 e o SQL corretivo já aplicado, apenas para referência. Não execute os SQL novamente.

Teste em janela anônima ou outro dispositivo, aceite a permissão e envie uma resposta de outro usuário. Teste ambos os temas, o dashboard e os formulários. Som/vibração de push dependem do sistema operacional.
